# Daily Floor 引き継ぎ書

## 何のために作ったか

Daily Floor は、目的作成、今日の1歩の達成、振り返り、日記を1つの生活タイムラインにまとめるPWAです。

先延ばしを怠惰ではなく、重さ、不安、眠気、迷い、自己批判が絡む行動停止として扱います。通常量を押し付けず、floorアクション、短い記録、休養ログも有用な成功/データとして扱います。

## 参考アプリから学んだこと

添付IPAから確認できたDay Oneの構造は、Today、Journal/Timeline、Entry作成、検索、カレンダー、メディア、テンプレート、プロンプト、音声/写真、Intentによる作成・追記・検索・日表示です。

Daily Floorでは、ブランド資産や文言をコピーせず、以下の構造だけを学びました。

- Todayは、その日の入口
- Journalは、リスト/カレンダー/メディアで見返す場所
- 新規作成は、右下からすぐ入れる
- 保存後は、どこに記録されたかを明確にする
- 日別・検索・タブで、情報の探し方を複数持つ

## Daily Floor独自の導線

- 今日: 目的を見て、今日の1歩を完了し、日記や休養ログも残す
- 目的: 目的名、理由、今日の1歩、floorアクション、もし/その時は、共有候補を保存する
- 振り返り: 予定、実際、学び、次の1歩を保存する
- ジャーナル: 新しい順のタイムライン、カレンダー、メディア、目的履歴を見る
- More: 操作ガイド、ボタン挙動、参考資料、バックアップ、設定を見る

## 取り入れた考え方

- 小さい1歩: 重い日は通常量を下げ、floorアクションだけで接触を保つ
- もし/その時は: 迷う場面と次の行動を先に結ぶ
- 行動の記録: 気分が整ってから動く前提にせず、行動と環境を事実として残す
- AAR型振り返り: 予定、実際、理由、次に変えることを短く見る
- 睡眠と生活リズム: 断定せず、睡眠や活動量の変化を共有候補として記録する

## 医療安全

このアプリは医療アプリではありません。

禁止:

- 診断
- 服薬助言
- 治療判断
- 医学的な断定
- ユーザー状態の推定

許可:

- 事実ログ
- 共有候補
- 注意して見たい変化
- 目的と次の1歩

## Local-first / PWA

- GitHub Pages-only
- React / TypeScript / Vite / PWA / Service Worker
- IndexedDBのみ保存
- 外部DB、外部分析、外部ログ、バックエンドなし
- Hash routing
- 初回ロード後はオフラインで開ける
- JSON/CSV/ICSでエクスポート

## 日記PWAへ引き継ぐべきこと

日記PWAでは、入口を「長文を書く」だけにしないでください。

入口例:

- 1行だけ書く
- 気分だけ残す
- 写真や添付だけ残す
- 後で書く枠を作る
- 休養ログを残す
- 目的の達成や振り返りを日記に変換する

タイムラインでは、空白日を責めず、短い記録も同じ重さで表示します。保存後は「何を保存したか」「どこで見返せるか」を必ず表示します。

## 次の開発者への注意

- 謎アイコンを置かない。意味が不明なボタンにはラベルを付ける
- 保存ボタンと画面移動ボタンを区別する
- ガイド画像は実アプリと一致させる。外部スクリーンショットのコピーは使わない
- `floor` は「最低限の接触」の固有語として扱う
- 医療判断ではなく、記録と共有候補に徹する
