# Daily Floor Product Spec

Daily Floor は「先延ばしは怠惰ではなく感情回避として扱う」ことを中心原則にする。目的作成、今日の1歩の達成、振り返り、日記タイムラインを中核にし、floorレベルの行動、短い記録、休養ログを失敗扱いしない。

主要機能:

- Today / Journal / More の3導線
- 目的作成: 目的名、理由、今日の1歩、floorアクション、もし/その時は、共有候補
- 達成: 今日の1歩を保存し、目的イベントと日記エントリーに同時記録
- 振り返り: 予定、実際、学び、次の1歩を保存し、ジャーナルへ反映
- 日記: 1行、気分、写真、添付、状態、休養、後で書く
- ジャーナル: リスト、カレンダー、メディア、目的履歴
- ガイド: 実アプリに一致するボタン説明と導線説明
- 状態メモとエネルギー判定 A/B/C/D/R
- 既存互換: タスクごとの normal / low-energy / floor / contact goal
- 感情ラベル、if-then、報酬バンドル、5分タイマー、開くだけ、休養ログの6段階カスケード
- 睡眠、昼寝、カフェインの事実ログ
- 夜レビュー
- Web Worker を使った週間集計と共有用 Markdown
- JSON/CSV/Markdown/ICS エクスポート
- IndexedDBローカル保存、PWAオフライン対応

禁止:

- 外部DB、外部分析、外部ログ
- 診断、服薬助言、治療判断
- 恥や失敗を強める表現
- 外部スクリーンショットをガイド画像としてコピーし、実アプリと不一致にすること
